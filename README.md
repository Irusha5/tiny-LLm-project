# My Tiny LLM Project

For this project I used TinyStories dataset.

What I did:
- Load 100 stories from TinyStories (streaming because full download was big)
- Made a simple char-level tokenizer
- Built a small transformer model with pytorch
- Trained it for 300 steps
- Loss started at 4.5 and went down to 2.3, so it is learning
- It can generate stories when I give prompt like "Once upon a time"

File is Untitled26.ipynb

It was fun to do.
